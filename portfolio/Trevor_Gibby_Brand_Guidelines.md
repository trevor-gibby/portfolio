# Trevor Gibby Brand Guidelines

## Brand Direction

A modern, clean, professional, technology-forward visual identity
inspired by Apple, Linear, Vercel, and contemporary developer tooling.

------------------------------------------------------------------------

# Typography

## Primary Heading

-   **Font:** Manrope
-   **Weight:** 800 (ExtraBold)

``` css
font-family: "Manrope", sans-serif;
font-weight: 800;
```

Used for: - Trevor Gibby - Major page headings - Hero titles

------------------------------------------------------------------------

## Secondary Heading

-   **Font:** Space Grotesk
-   **Weight:** 500
-   **Letter Spacing:** 0.18em
-   **Transform:** Uppercase

``` css
font-family: "Space Grotesk", sans-serif;
font-weight: 500;
letter-spacing: 0.18em;
text-transform: uppercase;
```

Used for: - FULL STACK ENGINEER - Section labels - Navigation accents

------------------------------------------------------------------------

## Body Text

-   **Font:** Inter
-   **Weight:** 400--500

``` css
font-family: "Inter", sans-serif;
```

------------------------------------------------------------------------

## Monospace

-   JetBrains Mono

For: - Code - Terminal snippets - Technical callouts
